## ccrの設定手法について
duty比はCCRがARR+1の時に1.0となります(リファレンス参照)\
CCRが0のときはduty比0.0です

16bit timerにおいてARRをUINT16_MAX(65535)に設定している場合，duty比1.0でCCRを計算する際，ARR+1=65536となり，オーバーフローして0と解釈されてしまいます\
32bit timerにおいてARRをUINT32_MAX(4294967295)に設定している場合も同様です\
オーバーフローを防ぐため，uint64_tで計算し，CCRがオーバーフローする場合は最大値に丸めます

32bit timerにおいてARRをUINT16_MAX(65535)に設定している場合，このプログラムでは不必要に65535まで丸められてしまいます\
バグです．ですが，影響があまり大きくないしスマートな解法が思いつかないので，このままになっています
